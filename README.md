# 《玉子市场》日常续写集

这里记录了兔山商店街的日常故事。每一集都围绕着商店街的季节更替、微小变化与温暖的人情展开。

## 第一集：风铃与热茶

十月的最后一个星期五，商店街顶棚的藤蔓叶子全枯了。冷风顺着石板路两头往里灌，吹得鱼店门前的塑料彩旗哗啦啦响。

北白川玉子把最后几串红豆年糕摆进木盘。热气刚冒出来，就被风吹散了。她把冻得发红的手塞进围裙兜里，望着街对面。

“大路家”的挂炉里正烤着红薯，甜香和炭火气飘了大半条街。饼藏的爸爸大路吾平正举着铁铲，一下下翻动着砂砾。

常盘绿推开 Tama-ya 的木门，把一条厚实的绿格子围巾围到玉子脖子上。围巾上带着樟脑丸和肥皂的干净味道。

“史织今天要在图书馆留到很晚，”小绿帮玉子拍掉肩上的面粉，“神奈去木材厂挑做冬日看板的松木了。今天只有我们两个。”

“谢谢你，小绿。”玉子把脸埋进围巾里，声音闷闷的。

街角的唱片店里传出沙沙的黑胶音乐。八百比邦夫坐着藤椅，在门口用小炉子煮着大麦茶，茶香里夹着烟草味。

一个套着旧大衣的修长身影在唱片店门口停下。那人背着个黑色帆布包，手里拎着一架有些掉漆的单反相机。

饼藏吸了习惯，把相机的镜头盖扣上。

“我回来了。”他站在 Tama-ya 的台阶下，看着玉子。

玉子从围裙里伸出手，抓住围巾的边角：“东京冷吗，饼藏？”

“差不多，就是风大。”饼藏走上台阶，把帆布包搁在柜台上。他从包里掏出一个纸袋，递给玉子。

袋子里装着几颗青绿色的柠檬。

“同学在和歌山寄给我的。他说煮茶的时候切两片放进去，嗓子会舒服点。”饼藏挠了勺后脑勺，视线落在玉子的白围裙上。

小绿在一旁叠着空木盘，木盘碰撞发出沉闷的声响。

“晚上去洗澡吗，饼藏？”小绿看着他。

“去。我爸说今晚‘宇治川’有柚子汤。”饼藏拎起包，朝街对面的自家店铺走去。大路吾平看见儿子，大声训斥着让他赶紧过去帮忙翻红薯。

玉子拿出一颗柠檬。柠檬皮很硬，带着雨水洗过后的清香。

她用小刀切下两薄片，放进刚泡好的粗茶里。热气托着柠檬 and 茶叶的味道升上来，熏得她眼睛有些湿。

隔着石板路，饼藏已经套上了大路家的灰色围裙，正蹲在炉子前，用扇子用力扇着炭火。灰烟呛得他咳嗽起来，大路吾平在他脑袋上拍的一记。

玉子捧着茶杯，小口喝着。微酸的茶汤顺着喉咙下去，把一整天的寒气都驱散了。

她看着对面的忙碌，轻声说：“真暖和啊。”

## 第二集：肥鸟与冬眠毯

十一月的清晨，白霜在屋瓦上结了薄薄一层。

“哎呀呀，本王的高贵羽毛都要被这平民窟的冷风吹得失去光泽了！”

Tama-ya 二楼的窗台前，德拉·达高南池正用它短小的翅膀拼命裹紧自己的身体。由于在兔山商店街吃了太多的高档年糕，它看起来比去年冬天又圆了整整一圈，活像一个长了尖嘴的白色糯米团子。

玉子正蹲在地上给妹妹馅子系围巾，闻言忍不住笑起来：“德拉，明明是你自己昨晚偷吃了三个留给客人的豆沙大福，才胖得飞不起来了吧？”

“胡说！那是身为王室信使必不可少的能量补充！”德拉扑棱着翅膀，试图飞上书桌，结果肚皮重重地在桌角蹭了一下，狼狈地滚回了地板上，发出一声沉闷的“叽”。

“德拉，你太吵了。”馅子叹了口气，背起红色的双肩书包，“我出门了。”

“路上小心，馅子！”玉子挥了挥手。

今天商店街的大家都显得有些忙碌。花店的香织小姐正把一盆盆耐寒的仙客来搬到门口，玩具店的老板戴着厚厚的手套，在给橱窗上的木质玩偶擦拭灰尘。

玉子在 Tama-ya 门口摆好冬日看板时，牧野神奈正抱着一大卷毛毡和木条走过来。她嘴里还咬着几根小铁钉，含混不清地打招呼：“早上好，玉子。今天要做‘防寒工作’了。”

“防寒工作？”玉子好奇地凑过去。

“嗯。要给长椅做垫子，还要给路灯柱子围上稻草。不然它们冬天会感冒。”神奈一脸严肃地用皮尺测量着 Tama-ya 门前长椅的长度，最后得出一个数字，“很好，这里需要三点五只德拉宽度的毛毡垫。”

“喂！平民女孩！本王可不是度量衡！”坐在柜台年糕筐里打盹的德拉探出头来，愤怒地大叫。

常盘绿拎着一袋刚从杂货铺买来的红豆走过来，伸手戳了戳德拉圆滚滚的肚皮：“神奈，如果把这家伙塞进毛毡垫里，说不定会很保暖哦。”

“哦，天然羽绒，密度很高，可行。”神奈非常认真地托着下巴观察德拉。

“呀——！谋杀皇室！玉子！快救本王！”德拉吓得缩进年糕筐最深处，用翅膀捂住脑袋。

街角传来一阵自行车铃声。朝雾史织戴着红色的毛线手套，慢慢在 Tama-ya 前停下。她从车筐里拿出一个用碎布头拼贴缝制的小毯子。

“那个……我在家里试着做了这个。”史织有些不好意思地把毯子递给玉子，“听说冬天鸟类需要更暖和的窝，我想着德拉也许用得上。”

毯子是用各种颜色的小碎布拼成的，一角还歪歪扭扭地绣了一朵小黄花，针脚细密而温暖。

德拉从年糕筐里探出一只眼睛，随即像滑雪一样“出溜”一下钻了出来。它用嘴喙叼住毯子的边角，眼角竟渗出了几滴亮晶晶的眼泪。

“呜噢——！史织小姐！您真是不毛之地的天使！本王决定了，从今天起，您就是本王在兔山商店街唯一的王妃！”

“好狡猾的肥鸟，竟然独占了史织的礼物！”小绿笑着去揪它的尾巴。

“放开本王！本王要和冬眠毯融为一体！”德拉死死用爪子揪着小毯子，在木地板上翻滚着，最后成功地把自己裹成了一个彩色卷饼。

商店街的石板路上，大路吾平正大声地和对面的北白川豆大争论着今年冬至是吃南瓜年糕还是红豆年糕。饼藏推着自行车走过，习惯性地朝 Tama-ya 的方向看了一眼，正好看见玉子和女孩子们围在一起，看着地上的“德拉卷饼”笑得直不起腰。

阳光穿过商店街有些漏风的顶棚，暖洋洋地洒在石板路上。

德拉舒服地打了个饱嗝，在彩色小毯子里蹭了蹭，满足地闭上了眼睛。冬天的脚步虽然近了，但兔山商店街的空气里，依旧满是让人安心的甜香。

## 第三集：红书包与初雪预报

天还没亮，空气冷得像凝固了一样。

北白川馅子把红色的双肩书包放在玄关的地板上，又紧了紧脖子上的黄色围巾。书包的拉链上挂着一只小小的木质兔子挂件，那是去年生日时，神奈用边角料刻给她的。

“今天预报说有初雪哦，馅子。”玉子揉着面团，探出头来叮嘱道。她的鼻尖上还蹭着一点白白的面粉。

“只是‘可能’啦。”馅子叹了口气，换上有些硬邦邦的小皮鞋。

她拉开门。冷风一下子扑了进来，吹乱了她额前的刘海。街上空荡荡的，大部分店铺都还没开门，只有肉铺的清水先生正在往外搬今天刚送来的新鲜肉排，嘴里吐着白色的哈气。

馅子沿着石板路慢慢往前走。

“哟！小馅子，起得真早啊！”

德拉像一团融化的棉花糖一样，从二楼的窗台上滑了下来，扑棱着翅膀落在馅子的红色书包上。它沉重的肉身压得红色皮革发出一声细微的抗议。

“德拉，你太重了，快下去。”馅子侧了侧肩膀，想把它抖下来。

“没礼貌的丫头！本王可是来为你保驾护航的！”德拉用爪子牢牢扣住书包带子，神气活现地挺起胸膛，“况且，本王在温暖的红色真皮宝座上，感到十分舒适。”

馅子无奈地翻了个白眼，索性由着它去了。

走过大路家门前时，二楼的窗户突然打开了。饼藏正睡眼惺忪地揉着眼睛，头发乱蓬蓬地翘着。他撑着窗台，正打算像往常一样伸个懒腰，结果一眼看到了背着肥鸟的馅子。

“早上好，馅子。”饼藏有些沙哑地打了个招呼，随即没忍住哈欠。

“饼藏哥，再睡下去就要迟到了哦。”馅子没有停下脚步，只是微微仰起头回了一句。

“啊……糟糕，今天轮到我值日了！”饼藏猛地一惊，手忙脚乱地关上窗户，屋里随即传来一阵兵荒马乱的穿衣声和塑料盆倒地的巨响。

德拉在书包上发出嘲讽的“咕咕”笑声：“愚蠢的平民少年，永远如此慌张。”

天空中慢慢飘起了碎屑一般的白色。

起初只是像细盐一样零星落下，掉在馅子黑色的皮鞋上，瞬间就化成了湿漉漉的水点。

“哇，真的是初雪。”馅子停下脚步，伸出戴着红手套的手。

一片细小的雪花落入她的掌心。她凑近去看，但还没来得及看清那精细的六角形图案，雪花就消失在温暖的红色羊毛里。

“哦！不祥的白色冷雨！本王的高贵羽毛会被冻住的！”德拉惊叫起来，拼命往馅子的帽子底下钻，把她的头发弄得一团糟。

“德拉，别乱动，很痒啊！”馅子笑着去抓它。

就在这时，街角的转弯处传来了同班女孩子们清脆的呼喊声：

“馅子——！”

同班的柚季和小百合戴着花花绿绿的毛线帽，正站在学校坡道的下方朝她用力挥手。

馅子亮起眼睛。她把帽子底下的德拉一把揪了出来，塞回自己的口袋里，然后迈开步子，在石板路上小跑起来。红色书包上的木兔子挂件随着她的步伐一晃一晃，发出清脆的“嗒嗒”声。

雪渐渐大了起来。

兔山商店街的石板路上，落下了第一层薄薄的、干净的白色。玉子正好推开店门，把刚写好的“初雪限定·雪见大福”木牌挂在最显眼的地方。

对面的饼藏正咬着面包，风风火火地从大路家冲出来。他在雪地里滑了一下，玉子在一旁忍不住笑出了声，而饼藏在雪花飘落的黄昏光线里，有些局促地拉了拉帽檐。

冬天的序幕，就这样在孩子们奔向学校的欢笑声，以及大福年糕散发的甜香中，静静拉开了。
