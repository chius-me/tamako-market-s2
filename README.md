## 第一集：风铃与热茶

十月的最后一个星期五，商店街顶棚的藤蔓叶子全枯了。冷风顺着石板路两头往里灌，吹得鱼店门前的塑料彩旗哗啦啦响。

北白川玉子把最后几串红豆年糕摆进木盘。热气刚冒出来，就被风吹散了。她把冻得发红的手塞进围裙兜里，望着街对面。

“大路家”的挂炉里正烤着红薯，甜香 and 炭火气飘了大半条街。饼藏的爸爸大路吾平正举着铁铲，一下下翻动着砂砾。

常盘绿推开 Tama-ya 的木门，把一条厚实的绿格子围巾围到玉子脖子上。围巾上带着樟脑丸 and 肥皂的干净味道。

“史织今天要在图书馆留到很晚，”小绿帮玉子拍掉肩上的面粉，“神奈去木材厂挑做冬日看板的松木了。今天只有我们两个。”

“谢谢你，小绿。”玉子把脸埋进围巾里，声音闷闷的。

街角的唱片店里传出沙沙的黑胶音乐。八百比邦夫坐着藤椅，在门口用小炉子煮着大麦茶，茶香里夹着烟草味。

一个套着旧大衣的修长身影在唱片店门口停下。那人背着个黑色帆布包，手里拎着一架有些掉漆的单反相机。

饼藏吸了习惯，把相机的镜头盖扣上。

“我回来了。”他站在 Tama-ya 的台阶下，看着玉子。

玉子从围裙里伸出手，抓住围巾的边角：“东京冷吗，饼藏？”

“差不多，就是风大。”饼藏走上台阶，把帆布包搁在柜台上。他从包里掏出一个纸袋，递给玉子。

袋子里装着几颗青绿色的柠檬。

“同学在和歌山寄给我的。他说煮茶的时候切两片放进去，嗓子会舒服点。”饼藏挠了勺后脑勺，视线落在玉子的白围裙上。

小绿在一旁叠着空木盘，木盘碰撞发出沉闷的声响。

“晚上去洗澡吗，饼藏？”小绿看着他。

“去。我爸说今晚‘宇治川’有柚子汤。”饼藏拎起包，朝街对面的自家店铺走去。大路吾平看见儿子，大声训斥着让他赶紧过去帮忙翻红薯。

玉子拿出一颗柠檬。柠檬皮很硬，带着雨水洗过后的清香。

她用小刀切下两薄片，放进刚泡好的粗茶里。热气托着柠檬 and 茶叶的味道升上来，熏得她眼睛有些湿。

隔着石板路，饼藏已经套上了大路家的灰色围裙，正蹲在炉子前，用扇子用力扇着炭火。灰烟呛得他咳嗽起来，大路吾平在他脑袋上拍的一记。

玉子捧着茶杯，小口喝着。微酸的茶汤顺着喉咙下去，把一整天的寒气都驱散了。

她看着对面的忙碌，轻声说：“真暖和啊。”

## 第二集：肥鸟与冬眠毯

十一月的清晨，白霜在屋瓦上结了薄薄一层。

“哎呀呀，本王的高贵羽毛都要被这平民窟的冷风吹得失去光泽了！”

Tama-ya 二楼的窗台前，德拉·达高南池正用它短小的翅膀拼命裹紧自己的身体。由于在兔山商店街吃了太多的高档年糕，它看起来比去年冬天又圆了整整一圈，活像一个长了尖嘴的白色糯米团子。

玉子正蹲在地上给妹妹馅子系围巾，闻言忍不住笑起来：“德拉，明明是你自己昨晚偷吃了三个留给客人的豆沙大福，才胖得飞不起来了吧？”

“胡说！那是身为王室信使必不可少的能量补充！”德拉扑棱着翅膀，试图飞上书桌，结果肚皮重重地在桌角蹭了一下，狼狈地滚回了地板上，发出一声沉闷的“叽”。

“德拉，你太吵了。”馅子叹了口气，背起红色的双肩书包，“我出门了。”

“路上小心，馅子！”玉子挥了挥手。

今天商店街的大家都显得有些忙碌。花店的香织小姐正把一盆盆耐寒的仙客来搬到门口，玩具店的老板戴着厚厚的手套，在给橱窗上的木质玩偶擦拭灰尘。

玉子在 Tama-ya 门口摆好冬日看板时，牧野神奈正抱着一大卷毛毡 and 木条走过来。她嘴里还咬着几根小铁钉，含混不清地打招呼：“早上好，玉子。今天要做‘防寒工作’了。”

“防寒工作？”玉子好奇地凑过去。

“嗯。要给长椅做垫子，还要给路灯柱子围上稻草。不然它们冬天会感冒。”神奈一脸严肃地用皮尺测量着 Tama-ya门前长椅的长度，结果得出一个数字，“很好，这里需要三点五只德拉宽度的毛毡垫。”

“喂！平民女孩！本王可不是度量衡！”坐在柜台年糕筐里打盹的德拉探出头来，愤怒地大叫。

常盘绿拎着一袋刚从杂货铺买来的红豆走过来，伸手戳了戳德拉圆滚滚的肚皮：“神奈，如果把这家伙塞进毛毡垫里，说不定会很保暖哦。”

“哦，天然羽绒，密度很高，可行。”神奈非常认真地托着下巴观察德拉。

“呀——！谋杀皇室！玉子！快救本王！”德拉吓得缩进年糕筐最深处，用翅膀捂住脑袋。

街角传来一阵自行车铃声。朝雾史织戴着红色的毛线手套，慢慢在 Tama-ya 前停下。她从车筐里拿出一个用碎布头拼贴缝制的小毯子。

“那个……我在家里试着做了这个。”史织有些不好意思地把毯子递给玉子，“听说冬天鸟类需要更暖和的窝，我想着德拉也许用得上。”

毯子是用各种颜色的小碎布拼成的，一角还歪歪扭扭地绣了一朵小黄花，针脚细密而温暖。

德拉从年糕筐里探出一只眼睛，随即像滑雪一样“出溜”一下钻了出来。它用嘴喙叼住毯子的边角，眼角竟渗出了几滴亮晶晶的眼泪。

“呜噢——！史织小姐！您真是不毛之地的天使！本王决定了，从今天起，您就是本王在兔山商店街唯一的王妃！”

“好狡猾的肥鸟，竟然独占了史织的礼物！”小绿笑着去揪它的尾巴。

“放开本王！本王要和冬眠毯融为一体！”德拉死死用爪子揪着小毯子，在木地板上翻滚着，最后成功地把自己裹成了一个彩色卷饼。

商店街的石板路上，大路吾平正大声地和对面的北白川豆大争论着今年冬至是吃南瓜年糕还是红豆年糕。饼藏推着自行车走过，习惯性地朝 Tama-ya 的方向看了一眼，正好看见玉子 and 女孩子们围在一起，看着地上的“德拉卷饼”笑得直不起腰。

阳光穿过商店街有些漏风的顶棚，暖洋洋地洒在石板路上。

德拉舒服地打了个饱嗝，在彩色小毯子里蹭了蹭，满足地闭上了眼睛。冬天的脚步虽然近了，但兔山商店街的空气里，依旧满是让人安心的甜香。

## 第三集：红书包与初雪预报

天还没亮，空气冷得像凝固了一样。

北白川馅子把红色的双肩书包放在玄关的地板上，又紧了紧脖子上的黄色围巾。书包的拉链上挂着一只小小的木质兔子挂件，那是去年生日时，神奈用边角料刻给她的。

“今天预报说有初雪哦，馅子。”玉子揉着面团，把沾满面粉的手在围裙上擦了擦，笑着探出头。

“只是‘可能’啦。”馅子拉开店门，换上有些硬邦邦的小皮鞋。冷风一下子扑了进来，吹乱了她额前的刘海。

街上空荡荡的，大部分店铺都还没开门，只有肉铺的清水先生正往外搬新鲜肉排，嘴里吐着白色的哈气。

馅子沿着石板路慢慢往前走，红色的双肩书包在晨光里格外显眼。

“哟！小馅子，起得真早啊！”

德拉像一团融化的棉花糖一样，从二楼的窗台上滑了下来，扑棱着翅膀落在馅子的红色书包上，沉重的肉身压得皮革发出一声细微的抗议。

“德拉，你太重了，快下去。”馅子侧了侧肩膀。

“没礼貌的丫头！本王可是来为您保驾护航的！”德拉用爪子牢牢扣住书包带子，神气活现地挺起胸膛，“况且，本王在温暖的红色真皮宝座上，感到十分舒适。”

馅子有些无奈，也只能由着它去了。

走过大路家门前时，二楼的窗户突然打开了。饼藏正睡眼惺忪地揉着眼睛，头发乱蓬蓬地翘着。他撑着窗台，正打算像往常一样伸个懒腰，结果一眼看到了背着肥鸟的馅子。

“早上好，馅子。”饼藏有些沙哑地打了个招呼。

“饼藏哥，再睡下去就要迟到了哦。”馅子微微仰起头回了一句。

“啊……糟糕，今天轮到我值日了！”饼藏猛地一惊，手忙脚乱地关上窗户，屋里随即传来一阵兵荒马乱的穿衣声。

德拉在书包上发出嘲讽的“咕咕”笑声：“愚蠢的平民少年，永远如此慌张。”

天空中慢慢飘起了碎屑一般的白色。

起初只是像细盐一样零星落下，掉在馅子黑色的皮鞋上，瞬间就化成了湿漉漉的水点。

“哇，真的是初雪。”馅子停下脚步，伸出戴着红手套的手。一片细小的雪花落入她的掌心，瞬间消失在温暖的红色羊毛里。

“哦！不祥的白色冷雨！本王的高贵羽毛会被冻住的！”德拉惊叫起来，拼命往馅子的帽子底下钻。

“德拉，别乱动，很痒啊！”馅子笑着去抓它。

“馅子——！”

街角的转弯处传来了同班女孩子们清脆的呼喊声。

柚季和小百合戴着花花绿绿的毛线帽，正站在学校坡道的下方朝她用力挥手。而在她们身旁，那个高个子的男孩龙也正有些局促地拍着围巾上的薄雪，视线在接触到馅子的那一秒，不自然地移向了旁边的电线杆。

“早上好，馅子！”柚季跑过来，一把挽住她的胳膊。

“早上好。”龙也低声说了一句，把手插进校服口袋里，耳朵在冷风里冻得有些红。

“早上好，龙也君……还有柚季，小百合。”馅子有些局促地把红手套背在身后，低着头，声音不知不觉小了下去。

德拉在馅子的口袋里探出小半个脑袋，压低声音在馅子耳边咕哝道：“哦？那个平民男孩的脸红得像熟透的番茄……”

“闭嘴，德拉！”馅子隔着口袋一把捏住了德拉的嘴喙，脸颊却比刚才更红了一些。

“怎么了，馅子？”柚季好奇地歪过头。

“没什么，我们快走吧，雪要变大了。”馅子有些慌乱地拉起柚季的手，快步朝校门走去。红色书包上的木兔子挂件随着她的步伐一晃一晃，发出清脆的“嗒嗒”声。

雪渐渐大了起来。

兔山商店街的石板路上，落下了第一层薄薄的、干净的白色。玉子正好推开店门，把刚写好的“初雪限定·雪见大福”木牌挂在最显眼的地方。对面的饼藏正咬着面包冲出来，在雪地里滑了一下。

而在坡道上，馅子和同伴们并肩走着。初雪落在他们的肩头，把少女微涩而甜美的青春期心事，也悄悄染上了一层温柔的白。

## 第四集：福豆、快门与立春之风

二月的第一个星期三，空气里还残留着化雪时的潮湿寒意，商店街顶棚边缘却已经挂上了一串串红绿相间的立春纸幡。

“大路家”和“Tama-ya”的柜台前，两个中年男人正隔着石板路，像两只斗鸡一样瞪着对方。

“豆大！你那毫无创意的白面团子，根本配不上立春的福豆！”大路吾平挥舞着手里的木铲，嗓门大得震落了屋檐下的积雪，“只有我们大路家特制的‘黄金烤红薯福豆年糕’，才能在这个冷得要命的春天给人带来福气！”

“哼，吾平，你懂什么！”北白川豆大双手抱胸，围裙上的面粉随着他说话的节奏一抖一抖，“福豆本来就要配最纯正的白盐年糕，那种杂七杂八的甜味只会破坏传统！玉子，今天把驱鬼用的福豆年糕多做五十个，我们要用味道彻底击败对面！”

“是——！”玉子清脆地应了一声。她正把捏好的圆形年糕排在竹盘里，鼻尖上沾了一点白色的面粉，笑眼弯弯地朝街对面看去。

饼藏正拖着一箱刚送到的福豆纸袋，有些尴尬地夹在父亲和北白川大叔的唾沫星子之间。他朝玉子使了个“真拿他们没办法”的眼色，玉子也回了他一个心领神会的浅笑。

“豆子和年糕，在空气动力学上是绝妙的组合。”

牧野神奈不知什么时候站在了 Tama-ya 的台阶旁。她戴着那顶有些旧的灰色毛线帽，手里拿着一把卷尺和几颗干瘪的黄豆。

“如果把豆子嵌在年糕表面，利用年糕的粘性，投掷时的空气阻力会减少百分之十二。”神奈一脸严肃地将黄豆在木板上排开，“也就是说，今年撒豆驱鬼的时候，我们可以投掷得更远、更准。目标：大路家的招牌。”

“喂！神奈！不要拿我家的招牌当靶子啊！”饼藏忍不住大声吐槽，揉着后脑勺走过来。

“饼藏，早上好。”常盘绿拎着一包洗干净的红豆走出来，斜眼看着他手里的单反相机，“今天也要当你的‘现场记录员’吗？”

“啊，嗯。”饼藏有些不好意思地拍了拍挂在脖子上的相机。这台相机还是他用打工攒的钱买的二手货，机身上的漆有些磨损，但被他擦得锃亮，“毕竟是立春嘛，大家在一起的画面，想用镜头记录下来。”

他的视线在说这话时，不自觉地往玉子站的方向歪了歪。

小绿注意到了他的目光，没有拆穿，只是微微叹了口气，把红豆递给玉子：“史织说她一会儿放学了直接过来，她今天带了从祖母家拿来的特制煎茶。”

“太好了，那我们一会儿在门口摆茶摊吧！”玉子高兴地拍了拍手。

午后，立春的祭典正式开始。商店街上挂满了五彩的纸幡，鱼店的清水先生已经戴上了红色的“赤鬼”面具，在石板路上张牙舞爪地跑着。孩子们手里抓着福豆，一边笑着叫着，一边把豆子砸在“鬼”的背上。

“鬼出去——！福进来——！”

玉子站在台阶上，捧着装满福豆的竹盒，脸颊因为兴奋和冷风而红扑扑的。她抓起一把豆子，用力朝清水先生扔去。

“鬼出去——！”

饼藏举着相机，站在人群之外。他的镜头一直紧紧跟着那个穿着深蓝色围裙、系着碎花头巾的身影。

在相机的取景框里，初春的微风吹散了玉子额前的碎发。她因为大笑而微微眯起的眼睛、鼻尖上那抹还没来得及擦掉的面粉、还有在阳光下闪闪发亮的白色蒸汽，一切都显得那么清晰、温润。

“咔嚓。”

快门声被商店街的欢笑声掩盖了。饼藏看着取景框里定格的画面，嘴角忍不住微微上扬。

“喂，饼藏！你这家伙在偷懒不扔豆子吗！”大路吾平一巴掌拍在儿子的肩膀上，差点把相机的带子拽下来，“拿着！去把北白川家的那个老顽固砸醒！”

“爸，你在说什么啊！”饼藏揉着肩膀，有些哭笑不得。

就在这时，一团白色的肥大身影突然从天而降，重重地砸在了大路吾平的脑袋上。

“噢——！愚蠢的凡人！竟敢阻碍本王品尝这高贵的福豆！”

德拉·达高南池用翅膀捂着嘴，它的嗉囊鼓鼓囊囊的，显然已经背着大家偷吃了不知道多少福豆，“本王宣布，这用火烘烤过的豆子，勉强能作为本王春季巡游的开胃菜！”

“你这只肥鸟！又在偷吃我家的福豆！”吾平气得大吼，挥舞着手里的红薯去赶它。

“哇啊——！玉子！救命啊！有红薯怪兽要谋杀皇室了！”德拉在空中划出一条笨拙的抛物线，狼狈地朝玉子飞去。

“德拉，别乱动！”玉子伸手去接，却因为德拉太重，脚下一滑，整个人朝后倒去。

“玉子！”

饼藏几乎是本能地丢下了手里的福豆袋子，一步跨上台阶，伸手去拉她。

温热的手掌在冷空气中碰撞，饼藏稳稳地抓住了玉子的手腕。因为惯性，玉子整个人撞进了他的怀里。

耳边是商店街嘈杂的哄笑声、风铃随风摆动的清脆声，还有对面唱片店里传出来的、沙沙的黑胶音乐。

空气里满是烘烤红薯的甜香，以及玉子身上淡淡的面粉味。

饼藏能感觉到玉子的呼吸轻轻拂过他的锁骨，他的心跳在这一瞬间快得像要从胸口跳出来一样。

“啊……对不起，饼藏。”玉子有些慌乱地站稳，松开了手。她的脸颊红得像熟透的小苹果，连耳朵尖都染上了红晕。

“没、没事，你没摔到就好。”饼藏触电般地收回手，把手插进裤兜里，指尖还残留着玉子手腕上温热的温度。他有些局促地别过头，看着对面的电线杆，觉得自己的脸烫得能把地上的雪融化。

小绿站在不远处，手里拿着一个空竹盒。她静静地看着这一幕，眼神在两人红透的脸上转了一圈，最后轻轻地垂下眼睫，嘴角露出一抹有些释然、却又带着微酸的温柔笑意。

“玉子，”史织抱着一只保温瓶跑过来，打破了这有些微妙的安静，“茶泡好了，温热的，刚好可以配福豆。”

“啊！史织，谢谢你！”玉子像是找到了救星一样，急忙跑过去帮史织倒茶。

神奈则蹲在两人刚才站立的地方，用一根小木棍在石板路上画着圈：“刚才饼藏跨步的速度是每秒三点二米，加速度极快，重力势能完美抵消。这是一次教科书般的救援。”

“神奈，别说了……”饼藏捂着脸，恨不得当场找个地缝钻进去。

傍晚，立春的喧嚣渐渐散去。

商店街的石板路上残留着一些碎豆壳，踩上去发出清脆的声响。冷风吹过，却不再像冬天那样刺骨，反而带了一丝泥土和嫩芽的、属于春天的湿润气息。

玉子捧着史织的温茶，靠在柜台前，看着对面大路家已经挂起的昏黄灯笼。

她把手放进围裙兜里，指尖碰到了刚才饼藏抓过的地方，那里似乎还残留着一丝异样的、让人心跳加速的温度。

而在街对面，饼藏坐在自己的小房间里。

他把相机里的胶卷洗了出来，借着微弱的光，看着那张在暖阳和飞舞的福豆中、玉子笑得最灿烂的照片。

他用指尖轻轻抚过照片里女孩的脸颊，轻声笑了起来。

立春的风，终于穿过商店街的顶棚，悄悄吹醒了每一个关于春天的秘密。
